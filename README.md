## What this is
A clap-first literacy karaoke studio. Rap delivers the existing curriculum. It does not replace it.

1. **Name Flo** (free door) — break any name into syllables, lock them to an 80 BPM bed, clap each chunk.
2. **Alphabet Buss Down** — letter name + baby sound, then a small match set.
3. **Freestyle Karaoke** — keep cadence / rhyme / syllable count. Swap 50 / 75 / 100 on an original bed. Never the loved-song master.

Score: Syllable 0.35 · Cadence 0.30 · Rhyme 0.25 · Fact 0.10. Pass if weighted ≥ 70 **and** syllable ≥ 60.
